Privacy Policy

Last updated: November 1, 2026

Gmail Multi MCP is a personal tool that runs only on its owner's computer. It is used only with the owner's own Google accounts.

Data accessed

With the account holder's permission, the tool uses the Gmail API to read, search, label, draft and send email in the connected account, only when the owner requests it.

Storage and sharing

  • Google sign-in tokens are stored only on the owner's local computer.
  • No email data is stored on any server run by this app, and none is sold or shared with third parties.
  • Email content is processed only to answer the owner's own requests.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
